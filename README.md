# NineView

让 Windows 文件资源管理器以紧凑列表和平铺布局显示文件缩略图。

[NineView](https://github.com/UnfiniSmile/NineView) 在已有 Explorer 窗口的文件区域中显示自定义视图，保留资源管理器的地址栏和导航栏，方便同时查看缩略图、文件名、大小等信息。

## 功能

- **列表与平铺视图**：列表显示名称、修改日期、类型和大小；平铺显示缩略图、文件名和文件大小。EXE 文件额外显示文件版本。
- **缩略图缩放**：支持 25%–800%，提供小、中、大、最大预设；各 Explorer 窗口可以分别调整。
- **文件大小显示**：KB 数值带千位分隔符，也可开启自适应文件大小单位。
- **排序提示**：点击列标题排序，箭头指示当前排序列及升序、降序方向。
- **文件操作**：打开、复制、复制路径、删除、撤销、重做、重命名、属性，以及在资源管理器中显示。
- **选择与拖放**：支持矩形框选、边缘滚动，以及与其他 Explorer 窗口之间拖放文件。
- **自动接入**：打开自动启用，检测后续打开的普通文件夹窗口，也可手动选择窗口接入。
- **外观**：支持 Windows 强调色、自定义颜色、经典主题。
- **在线更新与修复**：支持自动检测更新，也支持离线使用。

## 运行环境

- Windows 10 x64 为主要开发和测试环境。
- .NET Framework 4.7.2 或更新版本。
- 缩略图效果取决于 Windows 已安装的图片、Office、PDF 等文件处理程序。

其他 Windows 版本、混合 DPI 显示器以及第三方 Explorer 修改工具的兼容性，需在具体环境中验证。

## 开始使用

1. 从 [Releases](https://github.com/UnfiniSmile/NineView/releases/latest) 下载程序。
2. 运行 `NineView.exe`
3. 然后打开一个普通文件夹查看实现效果。

点击“还原”或退出主程序会恢复。最小化主窗口不会停止接入。

“此电脑”、主页、回收站、快速访问、搜索结果等虚拟位置不属于普通文件夹视图；进入实际文件夹后再使用。主窗口中的“刷新窗口”用于重新获取窗口列表。

## 设置

设置分为 **设置、主题、右键菜单、关于** 四个标签页。

| 项目 | 用途 |
| --- | --- |
| 设置 | 列宽、缩放、文件大小单位、视图模式、工具栏项目 |
| 主题 | 跟随 Windows 强调色、自定义颜色、经典主题 |
| 右键菜单 | 菜单项目、快捷键提示显示及快捷键启用开关 |
| 关于 | 版本、作者、项目链接及检测升级 |


在单个 Explorer 工具栏上修改缩放、单位或视图模式，只影响该窗口。一些模式默认隐藏，可在设置中打开。

## 快捷键

以下快捷键在 NineView 文件视图获得焦点时使用。快捷键提示与实际启用状态可以分别设置总开关和逐项开关；隐藏提示不会关闭快捷键。

| 操作 | 快捷键 |
| --- | --- |
| 打开 | Enter |
| 在资源管理器中显示 | Ctrl+Alt+R |
| 复制 | Ctrl+C |
| 复制路径 | Ctrl+Shift+C |
| 刷新 | F5 |
| 删除 | Delete / Ctrl+D |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y |
| 重命名 | F2 |
| 属性 | Alt+Enter |
| 上一级 | Backspace |


## 更新

更新窗口分为两个选项

- **延后一星期**：保存延后时间，暂缓启动时的更新提醒。
- **立即更新**：下载软件，替换后自动重启。

也可以在“设置 → 关于”点击“检测升级”。手动检测不受一星期延后限制，有新版时会打开同一个更新窗口。

版本号采用 `年.月.日.次`。

更新下载临时存放在：

```text
%LocalAppData%\nineApart\Temp
```

新版确认启动后清理本次临时文件，失败时可能保留恢复所需文件。

## 证书与自动修复

网络不可用或 GitHub 无法连接时显示会显示离线提示，可正常使用。

程序检测到文件完整性异常、证书异常或其它异常时，会尝试下载官方版本进行修复。修复时会请求管理员授权。

如果 EXE 已损坏到无法启动，请手动重新下载，或者提[Issues](https://github.com/UnfiniSmile/NineView/issues)。

## 文件与配置

| 位置 | 内容 |
| --- | --- |
| `%LocalAppData%\nineApart\Settings` | 视图、主题、右键菜单及快捷键配置；启动时自动从旧目录迁移 |
| `%LocalAppData%\nineApart\Updates` | 更新延后时间、修复诊断日志 `repair.log` |
| `%LocalAppData%\nineApart\Temp` | 更新和修复临时文件 |
